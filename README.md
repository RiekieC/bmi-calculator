
# 🍏 Jerry's BMI Calculator

This is a simple Body Mass Index (BMI) calculator built with [Streamlit](https://streamlit.io/).

### 💡 What it does:
- Takes user input for **Height (cm)** and **Weight (kg)**
- Calculates BMI using the formula:  
  \[ BMI = Weight / (Height in meters)^2 \]
- Displays:
  - Your **BMI score**
  - A health **category** (Underweight, Normal, Overweight, Obese)
